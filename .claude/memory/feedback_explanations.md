---
name: Feedback sobre explicaciones
description: El usuario aprecia explicaciones claras con links de documentación específicos cuando el tema lo requiere
type: feedback
---

Al usuario le gustan las explicaciones conceptuales antes de las tareas.

**Why:** Le ayuda a entender el "por qué" antes de escribir código, no solo el "qué".

**How to apply:** Incluir links de documentación cuando el tema requiere profundizar (librerías nuevas, conceptos no triviales). No incluirlos para conceptos simples o ya vistos. Los links deben apuntar a la sección exacta, no a la doc general.
